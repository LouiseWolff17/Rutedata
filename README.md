# RouteData

This repository contains the route map used in our **1st Semester Project (P1)** during my Bachelor's degree in Computer Science at Aalborg University.

The project, titled *Simulating the European Rail Network in Order to Find the Most Time-Saving Potential Infrastructure Improvements*, focused on simulating parts of the European railway network to investigate which infrastructure improvements could reduce travel times and make train travel more attractive.

The repository contains the map presented as **Figure 5.1 – Routemap: Map of stations considered by the program** in the project report.

The map illustrates the train stations and routes included in the simulation and served as a visual representation of the railway network modelled in our project.
